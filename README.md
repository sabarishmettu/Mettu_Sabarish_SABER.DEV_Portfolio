## 🎯 Overview

This repository contains the source code for my personal portfolio. Built with modern web standards, smooth animations, and a distinct futuristic visual identity, it showcases my featured projects, services, technical skills, and experience.

* **Live Deployment:** [mettusabarish.vercel.app](https://mettusabarish.vercel.app/)
* **Focus Areas:** Full-Stack Web Development, Modern UI/UX, Performance Optimization, Responsive Design

---

## 🚀 Key Features

* **Cyberpunk Aesthetic:** Custom dark/red futuristic UI with neon glow accents and immersive typography.
* **Interactive Terminal / CLI:** Integrated CLI tool for direct command-line navigation and secrets.
* **Showcase Sections:**
  * **Projects:** Filterable showcase of production apps and experimental builds.
  * **Services:** Breakdown of web architecture, frontend interfaces, and backend systems.
  * **Metrics & Stats:** Live counters for completed projects, stack proficiency, and client work.
  * **Interactive Contact:** Direct lead form and social links.
* **Fluid Responsiveness:** Mobile-first layout designed to look sharp on everything from ultra-wide monitors to handheld screens.
* **Fast Load Times:** Static generation and assets optimized for instant delivery via Vercel Edge Network.

---

## 🛠️ Tech Stack

* **Core Framework:** Next.js / React
* **Styling & Design:** Tailwind CSS, Custom CSS variables, Lucide Icons
* **Animations:** Framer Motion
* **Deployment & Hosting:** Vercel
